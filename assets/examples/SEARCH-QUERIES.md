# Example image search queries

Drop a 16:9 image (recommended 1280x720) into this folder named `<id>.jpg` and it will
appear automatically on that technique's card and in the Gallery.

Use clean, legally reusable sources. Good options:
- Royalty-free / Creative Commons libraries (Pexels, Pixabay, Unsplash, Wikimedia Commons)
- Your own production stills or screenshots from videos you have permission to use
- Filter image search tools by usage rights / Creative Commons before downloading

Avoid copyrighted music-video stills unless they are clearly labelled placeholders for replacement.
